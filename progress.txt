## Codebase Patterns
- Use `urllib.request` with `loop.run_in_executor()` for async HTTP calls (avoids adding httpx/aiohttp deps)
- Server entry point: `src/server.py` with `asyncio.run(main())`
- Authentication: token-based handshake in `src/auth.py`, verified via `verify_token()`
- Config from environment variables in `src/config.py`
- Use `asyncio.wait_for()` with TimeoutError for handshake timeout
- Quality checks: `ruff check src/ tests/ && mypy src/ tests/ && pytest tests/ -v`
- CLI tool wrappers use `asyncio.create_subprocess_exec()` in `src/playerctl.py`
- Import from `collections.abc` instead of `typing` for generic types (AsyncIterator, etc.)
- Tests import from `src` package — run with `PYTHONPATH=.` or `pip install -e .`
