## Codebase Patterns
- LRC lyrics parsing: use `LyricsLine(timeMs, text)` data class; regex `\[(\d{2}):(\d{2})\.?(\d*)\]` with `fractional.length` switch for 2-digit (cents *10) or 3-digit (ms) precision
- Karaoke lyrics highlighting: `findCurrentLineIndex()` finds last timed line with `timeMs <= progressMs`; `LazyListState.animateScrollToItem()` for auto-scroll; conditional styling via `isCurrent` flag
- Android Gradle wrapper: generate with `gradle wrapper --gradle-version=8.4`; wrapper JAR and scripts not committed (generated locally)
- Android compilation: requires JDK 17 (not newer versions), use `JAVA_HOME` env var to point to correct JDK
- Mesh gradient background: use Coil `ImageLoader.execute()` with `BitmapDrawable.cast()` for bitmap extraction, then `Palette.from(bitmap).generate()` for color extraction on `Dispatchers.IO`
- Canvas animation pattern: `rememberInfiniteTransition` with `animateFloat` + `tween` + `RepeatMode.Reverse` for blob motion; `Brush.radialGradient` with alpha-faded colors for bloom effect
- API enrichment modules follow the same pattern: async function returns a dataclass, uses `urllib.request` with `loop.run_in_executor()`, `_parse_*` helper for response processing
- Android WebSocket client: OkHttp with pingInterval(30s), ConnectionState sealed class, token handshake on open, exponential backoff reconnection (BASE_DELAY_MS=1s, MAX_DELAY_MS=30s), requires CoroutineScope at construction
- UI mode transitions (Player↔Lyrics): AnimatedContent with slideInHorizontally + fadeIn togetherWith slideOutHorizontally + fadeOut; key on showLyrics boolean
- Track change animation: AnimatedContent with fadeIn() togetherWith fadeOut() around album art and metadata; key on playbackState.title; wrap AsyncImage in Box for weight compatibility
- Screen-wake reconnection: DisposableEffect + LocalLifecycleOwner.current observing Lifecycle.Event.ON_START in MainActivity; triggers viewModel.onScreenWake()
- Android buildConfig stored as buildConfigField in app/build.gradle.kts (WS_HOST, WS_PORT, WS_TOKEN)
- Android landscape mode forced via `android:screenOrientation="landscape"` in manifest
- LAN cleartext traffic enabled via `android:usesCleartextTraffic="true"` in manifest
- Android Gradle stack: AGP 8.2.2, Kotlin 1.9.22, Compose BOM 2024.02.00, OkHttp 4.12.0
- Android project structure: module under `android/` with standard Gradle layout
- Use `urllib.request` with `loop.run_in_executor()` for async HTTP calls (avoids adding httpx/aiohttp deps)
- Server entry point: `src/server.py` with `asyncio.run(main())`
- Authentication: token-based handshake in `src/auth.py`, verified via `verify_token()`
- Config from environment variables in `src/config.py`
- Use `asyncio.wait_for()` with TimeoutError for handshake timeout
- Quality checks: `ruff check src/ tests/ && mypy src/ tests/ && pytest tests/ -v`
- CLI tool wrappers use `asyncio.create_subprocess_exec()` in `src/playerctl.py`
- Import from `collections.abc` instead of `typing` for generic types (AsyncIterator, Awaitable, etc.)
- Tests import from `src` package — run with `PYTHONPATH=.` or `pip install -e .`
- Server broadcast pattern: manage client set with `difference_update()` to avoid ruff F823 (local var reference before assignment) – iterate over `list(clients)` snapshot when removing during iteration
- Command dispatch: use `dict[str, Awaitable[None]]` mapping with eagerly created coroutines, accessed via `.get()` to avoid IndexError
